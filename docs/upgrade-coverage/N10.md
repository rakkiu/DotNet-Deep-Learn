WebApplicationFactory tạo host TestServer và HttpClient test không gọi Internet. Test controller trực tiếp không xác nhận middleware/routing/formatters..
- [Chẩn đoán và kiểm chứng](https://client-ifz4.vercel.app/#/read/aspnet-integration-testing#debug): Chạy riêng test bằng --filter và đọc expected/actual status/body. Kiểm tra content root, environment Testing, connection lifetime và DB file cô lập. Nếu test pass nhờ fake, ghi rõ ranh giới chưa đi qua và thêm engine/pipeline test phù hợp..
- [Tài liệu chính thức và đọc tiếp](https://client-ifz4.vercel.app/#/read/aspnet-integration-testing#resources): tài liệu cụ thể ở cuối bài.

## [Nền tảng junior cần giải thích được](https://client-ifz4.vercel.app/#/read/aspnet-integration-testing#junior)

WebLab.Tests tham chiếu WebLab, dùng Microsoft.AspNetCore.Mvc.Testing cùng .NET10.0.14, xUnit v2 2.9.3 và runner công bố. Mỗi factory tạo DB file temp riêng và xóa sau Dispose; DataLab SQLite in-memory/connection lifetime được phân biệt. EF InMemory không thay relational constraints/SQL translation; cần SQL Server thật cô lập khi xác minh semantics SQL Server.

Test thay auth handler trong ConfigureTestServices để tạo principal cho role/owner; app source không trust X-Test headers. Form test lấy antiforgery cookie/token trước khi POST, không vô hiệu bảo vệ chỉ để test pass. Seed và reset phải có owner, không phụ thuộc dữ liệu cá nhân hoặc thứ tự test.

## [Đào sâu middle và các đánh đổi](https://client-ifz4.vercel.app/#/read/aspnet-integration-testing#middle)

Unit mock repository không xác nhận query provider; integration không thay browser test accessibility/keyboard. Chọn ranh giới fake đúng nhu cầu, không thay mọi dependency khiến test chỉ kiểm tra giả. Test auth bypass phải ở test assembly/config; Identity thực được test riêng. Transaction/conflict dùng hai context token trong DataLab; cancellation deterministic dùng TCS/controlled I/O chứ không Sleep.
