## [Nền tảng junior cần giải thích được](https://client-ifz4.vercel.app/#/read/csharp-arrays#junior)

int[2,3] có Length=6, GetLength(0)=2 và GetLength(1)=3; truy cập bằng [row,col]. int[][] là mảng reference tới từng mảng con, có thể khác độ dài và null. Mảng rỗng Length=0 vẫn là object hợp lệ; không có index 0 để đọc.

Array.Resize(ref a,n) có thể tạo mảng mới và gán lại biến a, không làm object mảng cũ tự đổi Length. Clone/Copy/ToArray copy phần tử; nếu phần tử là reference thì object được trỏ tới vẫn có thể dùng chung. Vùng phần tử liên tiếp của reference array chứa các reference, không bảo đảm các object nằm cạnh nhau.

## [Đào sâu middle và các đánh đổi](https://client-ifz4.vercel.app/#/read/csharp-arrays#middle)

Array covariance cho phép string[] nhìn như object[], nhưng runtime vẫn giữ kiểu phần tử thật: ghi một object không phải string có thể ném ArrayTypeMismatchException. Generic List<T> không có conversion covariance như vậy; đọc thêm variance trước khi suy ra IEnumerable<int> đổi được sang IEnumerable<object>. Span/Memory là view vùng dữ liệu có lifetime riêng, xem bài bộ nhớ.
