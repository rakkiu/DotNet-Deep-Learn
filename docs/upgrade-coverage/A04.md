## [Nền tảng junior cần giải thích được](https://client-ifz4.vercel.app/#/read/csharp-types#junior)

int là alias của System.Int32; bool, char, enum và struct là value types; string, object và class là reference types. default của field/phần tử int array là 0, nhưng local chưa gán bị definite-assignment error khi đọc. var suy luận kiểu cố định từ initializer, object chấp nhận boxing/reference, dynamic dời binding thao tác tới runtime. var x = null không đủ thông tin kiểu.

5/2 cho int là 2; (double)(5/2) là 2.0 vì chia trước cast; 5/2.0 là 2.5. Suffix m chọn decimal, L chọn long. Implicit conversion phải được ngôn ngữ cho phép; explicit cast có thể mất dữ liệu; parsing đọc text theo định dạng/culture. checked phát hiện overflow phép toán nguyên phù hợp.

int? là Nullable<int>: HasValue kiểm tra trước Value; ?? chọn mặc định, ?. truy cập có điều kiện, ??= gán nếu null. string? là annotation; null-forgiving ! chỉ tắt chẩn đoán của compiler tại đó, không kiểm tra runtime.

Bảng **Ba cách khai báo**: Cú pháp / Kiểu lúc build / Rủi ro. var x = 10 — int — Không thể gán string sau đó; object x = 10 — object, chứa int boxed — Unbox sang sai kiểu lỗi runtime; dynamic x = 10 — Binding động — Gọi member sai có thể lỗi runtime.

## [Đào sâu middle và các đánh đổi](https://client-ifz4.vercel.app/#/read/csharp-types#middle)

Copy struct chứa field List chỉ copy reference của field, không deep clone graph. Gán lại string tạo/tham chiếu tới giá trị chuỗi khác, không sửa instance cũ. Boxing int sang object và unboxing phải đúng kiểu đóng gói; chuyển int thành long là bước chuyển đổi riêng. decimal hữu ích cho số thập phân theo nghiệp vụ nhưng 1/3 vẫn không chính xác vô hạn và tiền cần quy tắc làm tròn/đơn vị.
